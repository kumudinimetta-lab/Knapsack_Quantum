# Data-only certificate selector: before computation

This is an additional diagnostic, not a novelty claim. A hindsight winner uses observed full tree size T, which is not freely available before quantum search. Test a deterministic alternative that uses only compiled predicate cost C, the chosen classical threshold, and a valid data-only upper certificate B.

For each candidate j, its safe pruning rule yields a tree contained in the tree counted by its certificate. For banks use the minimum of member certificates; for exact LP the minimum over the four bank-member certificates also covers the stronger LP tree. Thus T_j <= B_j. For a fixed common overhead h>=0, select the candidate minimizing (C_j+h)*sqrt(B_j), with deterministic ties root, bank2, bank4, LP. This selection uses no observed T or optimum to choose a bound. It preserves the candidate predicate's safety. It does not prove improvement over a different candidate, since conservative certificates can distort rankings. It does not synthesize a full walk or turn the expression into an implemented quantum runtime.

Evaluation uses the previously declared common complete cohorts and actual-T proxies only after selection. Report ratio against always-exact LP, hindsight regret, selected method counts and certificate host computation time. Classical certificate/compilation preprocessing is not free and is not converted to quantum gates. No machine learning, fitting, tuning or regression is used. Every negative result remains saved. This simple rule is a known upper-bound selection principle; only its specific scoped behavior is being tested.
