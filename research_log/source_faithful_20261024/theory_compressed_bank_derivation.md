## Known sources and assumptions

The underlying one-row LP dual is standard, not the candidate contribution.
Dey--Dubey--Molinaro, arXiv:2007.15192v4, Section 3 and equations (2)--(3),
already write the binary LP Lagrangian and reduced costs. Wilkening et al.,
npj Quantum Information 11,146 (2025), Supplement F.2 / arXiv:2310.06623v2
Appendix A.6.2, already use fractional greedy bounds inside quantum B&B.
Existing snapshots `.firecrawl/theory_search_dey_0.md` and
`.firecrawl/theory_search_dual_quantum_0.md` were inspected. Do not present
LP duality or an LP bound inside quantum knapsack as new.

Assume integer positive weights w_i and integer nonnegative profits v_i,
capacity W>=0, STATIC branching order equal to nonincreasing exact v_i/w_i
with deterministic ties. A prefix fixes items 0,...,d-1. Its accrued profit P
is an integer. Its feasible residual capacity is R=W-sum_{i<d}w_i*x_i>=0.
The suffix is exactly {d,...,n-1}. Define

F_d(R,lambda)=lambda*R+sum_{i>=d}max(v_i-lambda*w_i,0), lambda>=0.

The residual fractional LP value U_d(R) is min_lambda F_d(R,lambda). An
optimal lambda belongs to {0} union suffix item ratios. The full-node upper
bound is P+U_d(R). We will not assume unknown optimum/tree size to build a bank.

## A. Remove ratios above the root split without prefix enumeration

Let s0 be the root first nonfitting item after fractional greedy whole items.
If all items fit at root, they also all fit after any feasible prefix, so the
singleton bank {0} gives EXACT LP values at every prefix.

Otherwise root cumulative weight through s0 is >W, and through s0-1 is <=W.
At depth d<=s0, if suffix greedy split at s<s0, then
selected_prefix_weight + sum_{i=d}^s w_i > W. The left side is <=sum_{i=0}^s w_i,
which is <=W, a contradiction. At d>s0 any suffix item index is already >s0.
Consequently every reachable split index is >=s0, and there is an optimal
lambda <=rho0=v_s0/w_s0 for every reachable prefix LP. A bank containing 0
and ratios of indices >=s0 therefore already gives exact LP values at all
feasible prefixes. Repeated ratios are deduplicated. This is a structural
specialization to the exact efficiency-prefix order, not arbitrary branching.

More generally a multiplier lambda>rho0 is globally dominated by rho0 on
all such prefix states: each convex F_d has a minimizer <=rho0, so it is
nondecreasing above rho0, hence F_d(R,rho0)<=F_d(R,lambda). Removing these
larger multipliers cannot reduce any integer-pruning coverage.

## B. Quotient prefix states by integer accumulated profit

For fixed d, two prefixes with equal residual capacity R may have different
integer accrued profit P. For an integer threshold tau,

P+F_d(R,lambda)<tau iff F_d(R,lambda)<tau-P.

Therefore preserving pruning for EVERY integer tau requires exactly
floor(F_bank_d(R))=floor(U_d(R)), regardless of P. Because all dual values are
>=U, this is equivalent to at least one selected multiplier satisfying

F_d(R,lambda)<floor(U_d(R))+1.                         (coverage)

The inequality is strict. Equality at the next integer is NOT coverage.
No rounding is performed in implementation: cross-products can decide it.
This preserves integer-threshold pruning decisions, not exact rational LP
values. Noninteger accrued profits require a different lattice analysis.
Negative integer P would still cancel algebraically; negative item profits are
outside the stated greedy/LP assumptions, not a failure of integer cancellation.

Reachable residual capacities can be generated by exact weight subset-sum DP
over each prefix. A bitset S_d records sums <=W of subsets of the first d items.
S_0={0}; S_{d+1}=S_d union (S_d+w_d), truncated at W. R=W-s is reachable iff
s in S_d. This is pseudo-polynomial in W, not polynomial in the input bit
length, and preprocessing must be charged. It need not enumerate 2^d prefixes
or compute any optimum. High-W cases need a declared cap and can fall back to
the safe root-tail exact bank rather than silently claiming compression.

## C. Candidate finite-grid minimum bank via interval stabbing

Let Lambda be the increasing sorted list {0} plus distinct ratios at/below
the root split density (or {0} in the all-fit case). For every reachable state
(d,R), its coverage set is nonempty, since an LP-optimal grid multiplier exists.
Each F_d(R,lambda) is convex in lambda, being a linear function plus maxima
of affine functions. A strict sublevel set of a convex function on a line is
an interval; its intersection with ordered Lambda is a contiguous index range
[l(d,R),r(d,R)]. It can contain several distinct multipliers with different
rational bounds but the SAME floored bound. This is the possible compression.

The all-prefix integer-pruning bank problem over this FIXED FINITE GRID is now
choose the fewest candidate indices stabbing every such interval. A standard
greedy rule processes intervals by increasing right endpoint, choosing that
right endpoint whenever the last chosen point is left of the current interval.
Exchange argument: for the earliest-ending uncovered interval [l,r], any
feasible bank has a point p in [l,r]. Replacing p with r keeps all remaining
intervals that p hit and whose right endpoints are >=r: their left endpoints
are <=p<=r and their right endpoints >=r. Hence this replacement loses no
needed coverage; iterate. This establishes minimum cardinality ON Lambda,
not minimum circuit gates, minimum arbitrary-rational-multiplier bank or
optimal full quantum runtime. Standard interval-stabbing primary attribution
is being verified separately; the generic greedy method is not claimed new.

Verified standard-problem attribution: Jeff Erickson, *Algorithms*, first
edition June 2019, author's Chapter 4 (*Greedy Algorithms*), Exercises,
interval-stabbing exercise, https://jeffe.cs.illinois.edu/teaching/algorithms/book/04-greedy.pdf .
The extracted PDF lost exercise numbering, so no number is invented. An
instructor-authored Williams College assignment by Sam McCauley (2020),
Problem 1, explicitly states the increasing-right-endpoint greedy strategy:
https://williams-cs.github.io/cs256-f20/assignments/Assignment_3.pdf . These
establish that the combinatorial subproblem/strategy is standard, not a new
interval algorithm. The exchange proof above supplies our actual assumption
mapping. Two search hits were rejected for this purpose: Jens M. Schmidt's
*Interval Stabbing Problems in Small Integer Ranges* concerns reporting queries,
and Ben-David et al.'s 2012 *The Approximability and Integrality Gap of Interval
Stabbing and Independence Problems* primarily concerns d-interval generalizations.
Neither is misrepresented as the source of this simple finite-grid proof.

Candidate algorithm: exact prefix-weight DP -> reachable (d,R) states -> exact
LP value and multiplier coverage intervals -> greedy finite-grid stabbing ->
bank. The same compiled bank is static for all prefix depths and all integer
thresholds. It never selects multipliers using tree size, solution optimum,
quantum performance or random favorable cases. Circuit synthesis is OUTSIDE
this derivation pass.

## Pre-code counterexamples and limitations

1. KEEP strict coverage: one-item residual w=2,v=1,R=1 has U=1/2 and threshold
   1. Lambda=0 gives F=1, so its floor differs and it must NOT cover this state.
2. DISTINCT rational values need not imply different pruning: if U=1/2 and
   F=3/4, all integer threshold predicates agree though F!=U. An exact-value
   bank requirement would be unnecessarily strong for this purpose.
3. Empty suffix at R>0: U=0 and F=lambda*R. Any multiplier with lambda*R>=1
   fails integer coverage, so dropping 0 automatically is unsafe. It may be
   redundant on a particular finite grid only when another sufficiently small
   multiplier covers every such state; let the interval algorithm decide.
4. Arbitrary branch order: the claim that split indices never precede s0 does
   not apply if suffixes cease to be contiguous in efficiency order. Do not
   transfer the root-tail elimination to another branching heuristic.
5. All-fit root: blindly indexing a nonexistent split is invalid; singleton 0
   is exact for every suffix prefix-state by the earlier argument.
6. Restricting to the density grid may lose opportunities from off-grid rational
   multipliers whose coverage intervals overlap between candidate ratios. The
   greedy result is NOT a global smallest rational bank. A counterexample search
   for this limitation should be retained, not hidden if one is found.
7. Complexity barrier: exact prefix-weight reachability is a subset-sum question.
   A W-bit DP can be infeasible for large binary-encoded W. Declare this limit,
   charge preprocessing, preserve caps, and fall back safely. No generic strong
   compression or polynomial-bit-time claim is made.
8. Even a minimum-cardinality grid bank may be larger or costlier than one exact
   greedy LP scan. Compression alone does not imply a quantum resource advantage.
9. All possible prefixes is stronger than prefixes actually visited at one
   threshold. The construction deliberately avoids threshold/tree enumeration;
   do not claim that its selected bank is minimum for a particular detection tree.

Independent algebra/assumption review is REQUIRED before implementation or a
700-case claim. Novelty and publication significance remain UNRESOLVED.

## D. Candidate worst-case barrier, also derived BEFORE code

Even the globally data-aware minimum density-grid bank need not be small.
For n>=2 let q=floor(n/2), all weights w_i=2, capacity W=2*q+1 and
v_i=4*(n-i)+1 for indices i=0,...,n-1. Values are positive distinct odd integers
with gcd one; ratios decrease by 2, so there are no efficiency ties. The root
split item is q with residual capacity 1 after q whole items.

For each s in {q,...,n-1}, choose prefix depth d=s-q and assign ALL those prefix
bits zero. This reachable node still has R=W. Its suffix packs q whole items
then half of item s, so its LP value U is a half-integer. Its unique optimal
dual multiplier is lambda_s=v_s/2. Just above lambda_s, dual slope is
R-2*q=1; just below lambda_s, slope is R-2*(q+1)=-1. Every other candidate
density differs by at least 2. By convexity its dual objective is therefore
at least U+2. Lambda=0 is still farther away and cannot cover either.

The integer-pruning coverage threshold is floor(U)+1=U+1/2. Thus ONLY lambda_s
from the density grid covers this state. Every tail density q,...,n-1 is
individually forced. At depth n with the all-zero assignment, R=W and U=0;
all positive grid multipliers are >=5/2 and yield lambda*W>1, so ONLY 0 covers
that leaf state. Consequently the entire root-tail grid, n-q+1 multipliers,
is necessary for all-prefix/all-integer-threshold pruning in this family.

This is a candidate linear-cardinality barrier for the stated density-grid
problem, not an arbitrary-rational-bank lower bound or a hard-knapsack family.
Indeed unit-equal weights make the underlying optimization easy; what is hard
here is demanding one static dual bank reproduce every prefix LP threshold
predicate. The LP at depth n is not needed if leaf rejection is separately
implemented by the exact objective; dropping that requirement could remove
the forced 0, but the n-q forced distinct densities still give a linear barrier.
Independent review and exact checks are still required for this new barrier.

## E. Normalization limitation and unit-dummy repair

The parent reviewer correctly observed that the original equal-weight family
has gcd(weights)=2. Dividing weights by two and replacing capacity with
floor(W/2)=q preserves INTEGER feasible assignments but tightens the LP. The
original barrier is valid for its stated LP predicates; it must not be sold as
robust to competent integer-data normalization. This failed stronger inference
is retained, not discarded.

Repair proposed by the parent and independently checked here: retain n main
items as above, append one lowest-density dummy w=1,v=1. Keep W=2q+1. Main
densities are >=5/2, while the dummy density is 1. Gcd of weights and profits
is now one. The same reachable main-prefix states d=s-q have q whole main
items then half of main item s, before the dummy, so each main-tail density
remains forced. Adjacent main densities differ by 2; the closest extra dummy
density is at least 3/2 below the last main density, which still creates dual
gap >=3/2 > the half-unit integer-coverage slack. The all-zero complete leaf
has R=W>=3, so every positive grid multiplier >=1 gives F>=3>1, forcing 0.

Thus all n-q main-tail ratios plus 0 remain necessary, and these also suffice:
when a main split exists its density is retained; when the suffix is all-fit
lambda0 is exact; a split at the unit dummy has integer residual in [0,1),
therefore residual0, and any retained main density >=5/2 also minimizes its
zero-value residual LP. The dummy multiplier is redundant. The minimum grid
bank has n-q+1 entries on n+1 items, still linear. This is a barrier to static
all-prefix LP-predicate compression, not hardness or a quantum lower bound.
The underlying optimization remains easy. Tiny exact checks are pending.

## Pseudopolynomial preprocessing versus solving the problem

Reachability alone uses W-bit prefix DP. A classical profit DP can solve this
one-row knapsack in O(nW) elementary table updates; the proposed bank compiler
may do MORE work by testing multiplier coverage over reachable states. It is
therefore not a free accelerator for a single-instance end-to-end quantum
optimizer. Any scientifically defensible use is a stated offline circuit
compilation/resource-construction study, with preprocessing time/work charged,
or a separately justified reuse model. Reuse must not be invented after the
fact: changing weights/profits/capacity generally changes the compiled bank.

## F. Candidate DP-free sufficient compression (before any code)

To avoid W-bit reachability altogether, impose a stronger sufficient condition
covering ALL integer residual capacities for each possible split density, even
unreachable ones. Group equal positive efficiencies rho_g=a_g/b_g in lowest
terms; let L_g be the sum of weights of ALL original items with that density.
At a suffix the remaining part of the group weighs at most L_g. Include 0 to
cover every all-fit/empty-suffix case exactly.

If a candidate multiplier lambda lies between the immediately neighboring
DISTINCT efficiency breakpoints around rho_g (inclusive), no other density
breakpoint is crossed. Its dual loss relative to the optimal rho_g has the
form r_g*(lambda-rho_g) above rho_g, or
(remaining_group_weight-r_g)*(rho_g-lambda) below rho_g. Here r_g is the integer
capacity assigned fractionally to this equal-density group. In either direction
the loss is <=L_g*abs(lambda-rho_g). (At an adjacent breakpoint, the same
formula follows by continuity; its zero-cost neighboring group has no effect.)

The residual LP value has denominator dividing b_g; its distance to the next
larger integer is at least 1/b_g. Consequently

abs(lambda-rho_g) < 1/(b_g*L_g)

is sufficient for strict integer-pruning coverage for every such suffix/state.
Equal-density GROUP weight, not one split-item weight, is required: at a tied
density a nearby multiplier changes the treatment of the whole remaining group.
For the finite density grid, only rho_g and its immediate grid neighbors are
considered under this sufficient argument. They form a contiguous coverage
interval containing rho_g. Stab these at most n group intervals plus mandatory
{0} by the same greedy rule. This yields a DATA-ONLY sufficient bank without
enumerating residual capacities, solving subset sum or using an optimum/tree.

This criterion may retain the entire root-tail grid even if actual reachable
states permit much better compression. It is NOT a minimum integer-pruning
bank, only minimum cardinality for these conservative sufficient intervals.
The strict radius cannot be relaxed to nonstrict without a fresh proof, since
loss equal to the rational gap can cross an integer threshold. A multiplier
beyond an adjacent distinct density can involve additional slope terms, so the
simple L_g radius must NOT be applied globally across multiple breakpoints.
Independent review is required before implementing this optional construction.

Independent hardware/games review confirmed Section F before implementation:
on the adjacent-density segment the dual slope is r_g or r_g-L_suffix, with
0<=r_g<=L_suffix<=L_g; continuity handles adjacent endpoints. Its review
explicitly limits the result to sufficient intervals, not minimum actual bank.

## G. Off-grid limitation: concrete counterexamples, not a hidden caveat

Tiny normalized example: w=[1,1],v=[1,1],W=1. The density grid {0,1} requires
two entries. At the root U=1 but lambda0 gives F=2, so lambda1 is needed from
that grid; at the complete all-zero prefix U=0 but lambda1 gives F=1, so lambda0
is needed. Yet the singleton OFF-GRID bank {1/2} preserves all integer floors:
root1.5 ->floor1; depth1 excluded ->1; depth1 included ->1.5; allzero fullleaf
->0.5; one included fullleaf ->1; both included is capacity-infeasible.
Thus minimum-on-density-grid is strictly weaker than minimum among all rational
multipliers, even with gcd-normalized data.

The reviewer independently vertex-enumerated a related example
w=[9,9],v=[1,1],W=10 with singleton lambda1/11: six feasible prefixes and
0 floor errors; grid minimum two. It also independently found a three-item
example with grid minimum three and an off-grid two-entry bank. Raw records
and exact source are `reviewer_offgrid_analytic.py/json` and
`reviewer_offgrid_probe.py/json`. These strengthen the scope restriction;
no global arbitrary-rational minimum claim is made by the present compiler.
