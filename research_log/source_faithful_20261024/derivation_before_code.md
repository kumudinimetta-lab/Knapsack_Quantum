## Ideal arithmetic identities

All registers are little-endian. N=2^n. Let F be the canonical positive-phase QFT. If D_k|y>=exp(2*pi*i*k*y/N)|y>, then F^-1 D_k F|x>=|x+k modN>. The no-SWAP QFT used below is bit-reversed F. Its physical destination qubitj carries the phase associated with denominator2^(j+1), so constantk requires angle theta_j=2*pi*(k mod2^(j+1))/2^(j+1). Negativek reverses the sign. For a quantum summand a=sum_l a_l*2^l, use controlled phase angle2*pi*2^l/2^(j+1) from a_l to destinationj whenever j>=l. The summand is unmodified. Conditional constant additions use the single quantum flag as phase control. No opaque arithmetic function is simulated in place of gates.

The exact no-SWAP QFT sequence acts on destination qubitsj=n-1..0: H(j), then CP(pi/2^(j-k)) on(j,k) for k=j-1..0. Inverse gates reverse order and phase signs. Kernel tests must establish endianness/sign and clean source preservation before full predicates are accepted.

Classical constant comparisons use WilkeningE.5 orthogonal clauses. For x>c, for every bitj with c_j=0, require x_j=1 and all higher x_k=c_k. For x<c, for each j with c_j=1 require x_j=0 and all higher equal. Distinct clauses are mutually exclusive, so toggling the target for each clause equals OR. Negative controls are explicit X gates and are restored. An n-control target flip is decomposed by accumulating its AND into n-1 clean ancillas, applying one CX, and reversing the AND chain, matching the generic decomposition assumption in supplementE(i). The pilot uses a reusable serial chain; it does not use an undeclared optimized arbitrary MCX gate. Counts will include negative-control X gates even though the paper treats control polarity equally.

A quantum-quantum comparator needed by OUR cross-product reconstruction is not supplied as a released R1 LP gate list. We choose an explicit construction: for n-bit unsigned L,R, copyL into a clean n+1-bit word C (highbit0), subtractR mod2^(n+1) by QFT gates, copyC_n to the output flag, reverse subtraction and the copy. Since -(2^n-1)<=L-R<=2^n-1, the highbit is1 iffL<R. The extra sign bit prevents unsigned wrap from corrupting the comparison. This is a declared reconstruction choice, not attribution of this comparator to R1.

## Fixed-depth clean LP predicate and widths

Interface identical to the existing compact controls: classical instance (positive integer w,v; nonnegative W), classical depthd; quantum d-bit prefix (in exact stable decreasing-ratio order), tb=max(1,bit_length(sum(v)+1)) quantum threshold bits, output target, zero workspace. The action is target XOR [prefix infeasible OR U_LP(prefix)<tau], all inputs preserved and workspace reset. Empty/all-fit cases, strict equality, zero capacity/residual and ties are required.

Same scan/flags/lifetimes as the existing compact exact reconstruction: accumulate assigned weight and integer valueP, initialize residualR=W-weight, reject capacity separately, keep active/take/split flags as reversible history. Greedily fill the suffix; at the first split item reduce v_i/w_i=a_i/b_i, and compareP*b_i+R*a_i<tau*b_i. No split uses integerP<tau. Cross multiplication is OUR declared completion of the fractional bound absent from the released netlist; it is an elementary identity, not a new theorem or proof that a reference divider was removed. Products are repeated controlled additions of shifted quantum sources to clean accumulators; all are gate-level QFT networks. At each comparison uncompute products before register reuse; output-copy then reverse the entire forward work list.

Capacity width wb=bit_length(W+sumw)+1; P width vb=bit_length(sumv)+1 (both at least1). Common product width cb=bit_length(max(sumv*maxw+W*maxv,(2^tb-1)*maxw))+1. These cover all feasible live nonnegative operands. Infeasible-prefix residual wraps modularly but active0 makes those bound flags irrelevant; exact gate reversal still cleans it. Generic variable comparisons use a reusable cb+1 word, rather than interpreting a potentially wrapped original accumulator as signed. The Boolean flags are identical to the compact construction. No circuit choice uses optimum, tree size or favorable outcome.

## Precision, fairness and caps

Initial arithmetic uses ideal full QFT angles; no rotations are dropped. Floating-point simulation is judged against HARDCODED amplitude tolerance1e-8, which is a numerical check tolerance, not a fixed-point bound precision, QPU error rate or Clifford+T synthesis error. Primitive dense matrices are compared column-by-column to integer permutation references. Full compiled gates are simulated using Aer matrix_product_state with truncation_threshold0 and no finite bond cutoff where supported; inspect actual configuration and retain errors/time caps. Expected-output amplitude must be near +1, checking column phase as well as probability; this also bounds leakage to dirty workspace for those columns.

Common logical basis is arbitrary-angle {u,cx}, all-to-all connectivity, optimization_level0, no rotation-synthesis approximation. Both OUR source-based reconstruction and the existing compact exact/dual circuits are decomposed using the same installed Qiskit transpiler. Report qubits, u count, cx count and decomposed depth, plus native gate counts. No T-count, fault-tolerant time or device advantage follows. Report serial/no-control-copy choices; the authors' optimized E.3/E.5 parallelized schedule is not reproduced by this first pilot, so beating or losing to this reconstruction is not beating or losing to their best published method.

Initial bounded plan: dense adder/subtractor and comparator kernels at1-3bits; full clean predicate on tiny positive-integer cases (at most3items) with exact same prefix/threshold interface as compact controls. Matrix-product tests use explicit complete gate lists, never only an opaque arithmetic formula. Retain every mismatch, simulator failure, skipped/capped condition and phase error. Stop the affected correctness claim if any mismatch appears. Independent review is required before priority/performance claims. Expansion needs a successful scoped pilot and a reasoned resource budget, not a favorable result selection.

## Independent review and comparator sensitivity control before extension

Reviewer independently confirmed the QFT phase/endianness derivation and n+1 sign comparison. It flagged that the literal generic AND-to-ancilla + CX construction can inflate very small comparisons relative to direct gates. Therefore retain TWO explicit decomposition policies: source_generic follows the generic2(n-1)CCX+CX assumption; direct uses X/CX/CCX for0/1/2controls and, for n>=3, computes the firstn-1control AND into n-2ancillas, applies a finalCCX with the lastcontrol and target, then uncomputes. This costs2n-3CCX with n-2scratch, by direct counting of n-2forward and n-2inverse AND gates plus the finalCCX. Both implement the identical multi-control truth function and are source-derived reconstruction choices; neither is represented as reproducing the authors' optimized parallel schedule. Kernel tests cover both, and resource tables retain both rather than claiming a gain against an avoidably weak control. No production file is modified.
