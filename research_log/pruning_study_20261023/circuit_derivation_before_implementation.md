# Production research predicate derivations and bounds, before circuit implementation

2026-10-23. Candidate research implementation only; manuscript and existing code/raw artifacts remain unchanged. Parent independently audited exact rational comparison and root-dual weak duality before this extension. Primary arithmetic feasibility: Vedral, Barenco, Ekert, Physical Review A 54,147 (1996), Section III.1 subtraction/comparison and III.3 multiplication by controlled constants, https://arxiv.org/html/quant-ph/9511018v1 . No named optimized adder or divider is being claimed.

For an integer knapsack instance, positive integer w_i,v_i, W>=0, define S=sum(v), M=sum(w), m=#items; empty instance is permitted. The fixed order sorts exact Fractions v_i/w_i, stable on ties. Input registers hold m prefix bits, d in db=max(1,bit_length(m)) bits, tau in tb=max(1,bit_length(S+1)) bits. Bits after d are ignored; d>m produces prune=1. Both target inputs obey target XOR prune. All work registers start and end zero. Thresholds range over every encoded nonnegative integer, including 0 and 2^tb-1.

Capacity arithmetic width wb=max(1,bit_length(W+M)+1) covers prefix weight, W and their subtraction. If the subtraction underflows, its reversible modular value is ignored by the separate infeasible flag. This does not authorize comparing signed modular results to physical bounds.

Exact predicate: at the first fractional suffix item s, reduce a_s/b_s=v_s/w_s by gcd. For integer whole-item total P and residual r>=0, U=P+r*a_s/b_s, and U<tau iff P*b_s+r*a_s<tau*b_s. Strict equality is retained. At no split, compare P<tau. P<=S; r<=W on feasible branches. A common width cb=bit_length(max(S*max(w)+W*max(v),(2^tb-1)*max(w)))+1 covers the unreduced products and therefore the reduced products too. vb=max(1,bit_length(S)+1) covers P, and extra padding makes final unsigned comparisons nonoverflowing. Suffix scan stops after the first split; no suffix means integer P directly. All arithmetic gates remain reversible on infeasible inputs, whose irrelevant bound outputs are gated out.

Dual and finite bank: for each fixed data-only lambda=a/b, a>=0,b>0 in lowest terms, put r_i=b*v_i-a*w_i, N0=a*W+sum max(r_i,0), and loss L=sum_selected_assigned max(-r_i,0)+sum_excluded_assigned max(r_i,0). For every capacity-feasible completion z, b*value(z)<=N0-L by w(z)<=W and z_i*r_i<=max(r_i,0) for suffix items. Hence safe prune iff N0 < L+b*tau, or prefix capacity violation. This avoids a signed accumulator. L<=sum|r_i|. cb=bit_length(max(N0,sum|r_i|+(2^tb-1)*b))+1 prevents overflow. lambda=0 produces S minus excluded assigned values, the simple remaining-profit bound.

For a finite bank of fixed rational multipliers lambda_1,...,lambda_q, each U_j is a valid upper bound; U_bank=min_j U_j is valid, and U_bank<tau iff OR_j[U_j<tau]. This has no false reject of a feasible completion with value>=tau. No common denominator is needed: separately compare N0_j<L_j+b_j*tau and OR the flags. Capacity accumulation and depth comparison flags can be shared; loss registers and comparator temporary gates are separate in this transparent compiler. The classical bank-selection rule depends only on weights, values and W; it must never use optimum, threshold-tree size, or gate-resource outcomes. Arbitrary user-supplied banks are valid under a>=0,b>0. An empty bank is invalid.

The bank always includes root split multiplier when nonempty instance has a split, else 0. A finite bank may equal exact node LP on some nodes and be looser on others. It can cost more without shrinking the tree. This is a falsifiable tradeoff, not a promised speedup. A bank containing 0 is never weaker than the simple profit bound. A bank containing the root lambda is never weaker than that same root-dual bound. Neither statement is a priority claim.

Production construction has explicit limits on wires, gates and elapsed build seconds; cap exceptions retain partial counters and cannot become successful circuit results. Resource counts are DERIVED from actual X/CX/CCX lists; sparse permutation basis propagation is SIMULATED; tree enumeration is MEASURED classical work; input constants/caps are HARDCODED. No quantum runtime or hardware result is inferred from these counts. Full walk/reflection synthesis remains outside the predicate scope.

Required falsification tests: empty items, capacity0, allfit, overweight items and prefixes, identical ratios, gcd reduction, invalid depth, arbitrary irrelevant suffix bits, tau0/max, strict equality, both target inputs, all workspace cleanup. Each scoped report must include mismatch counts. General correctness depends on the derivation, not on merely finite tests. Independent dense Qiskit propagation is allowed only when circuit fits a strict qubit cap; skipped cases are retained.

## Matched fixed-point single-scan control, added before implementation

Use the same depth-controlled scan and integer whole-item P register as the exact single-scan builder. Let k=bit_length(Wmax^2), so 2^k>Wmax^2; q_i=floor(2^k*v_i/w_i) is compiled classically. At split, A=2^k*P+r*q_s represents a downward-truncated bound. Its loss is 0<=U-A/2^k<r/2^k<Wmax/2^k<1/Wmax. For integer tau, if exact U<tau, then tau-U>=1/w_s>=1/Wmax because U has denominator dividing w_s. Thus A/2^k<=tau-1/Wmax holds. Conversely if U>=tau, A/2^k>tau-1/Wmax, so it cannot pass that prune comparison. Equivalent integer nonstrict test: A*Wmax+2^k<=tau*2^k*Wmax. At no split use P<tau, which is equivalent to the same test for integer P. Exact ratio ordering is preserved; truncated efficiencies do not determine item order.

Choose fixed-point product width above max((S*2^k+W*max(q_i))*Wmax+2^k,(2^tb-1)*2^k*Wmax). All operands are unsigned and nonoverflowing on feasible branches. This is the same semantic safe fixed-point rule as the legacy circuit, with coherent single-scan dispatch; it separates dispatch effects from arithmetic effects. Width/gate optimizations (integer P then wire-shift) are documented and are not claims of optimality. Legacy out-of-place Boolean arithmetic may inflate ancillas compared with published optimized arithmetic; no reported count is a lower bound or best-known count.
