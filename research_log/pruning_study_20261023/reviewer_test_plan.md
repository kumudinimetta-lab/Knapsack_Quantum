Independent exact LP reference: enumerate fractional-knapsack polytope vertices rather than invoking the implementation's greedy LP routine. A vertex of one-capacity box-constrained LP can be represented by an integral subset and at most one fractional item; enumerate all integral subsets and each remaining item, fill a fraction between zero and one, and take the maximum value. Prefix weight/value is accounted before suffix enumeration. This is a reference algorithm for small tests, not a new theorem or complexity claim. Use deterministic ratio order only to interpret prefix positions; the reference bound does not use the implementation's fractional scan.

Shared overhead sensitivity derivation: for a weaker predicate with compiled cost Cw and tree Tw, and stronger predicate Cs and tree Ts (Tw>=Ts), an actual-tree proxy is (C+h)*sqrt(T). Put r=sqrt(Ts/Tw). If r<1, the weaker predicate's proxy is smaller only when h < (r*Cs-Cw)/(1-r), provided the right side is positive. If r=1, comparison reduces to Cw<Cs. This is algebra on a declared model, not a new algorithm, hardware runtime prediction or free use of an unknown tree bound. A common certified B can cover both methods, but may produce identical query schedules and cannot be substituted for the observed T while retaining the observed tree advantage.
