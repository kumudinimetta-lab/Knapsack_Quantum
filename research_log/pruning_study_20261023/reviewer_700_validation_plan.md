# Scoped 700-input compiled-gate validation plan

23 October 2026, recorded before this new run. This is not exhaustive simulation of all prefix/depth/threshold encodings. The tiny independent vertex reference remains in reviewer_production_probe.json.

Use every one of the saved main700 records in inputs.json, sorted in saved order; retain the immutable registry and source hashes. The three circuit families are exact single scan, safe fixed-point single scan, and root dual. On every instance test every representable valid depth 0..n, plus every invalid depth encoding when present. At each depth test all-zero selection bits, all-one selection bits (including ignored suffix bits), and a fixed-seed random full selection encoding. Deduplicate coincident encodings. Test integer thresholds zero, maximum encoded threshold, a random threshold, and both sides of the floor of the independent exact LP and root-dual bounds, clipped to the encoded domain. Test both initial output-bit values and all workspace cleanup. Store every selected input encoding, reference flag and seed; inputs are sampled, not exhaustive.

Large-input reference uses exact Fraction greedy residual LP, independently written outside the production module. It does not reuse the gate arithmetic or the fixed-point rule. This reference is cross-checked separately on tiny instances by LP vertex enumeration. The root-dual reference uses the direct Lagrangian envelope, not the circuit's reduced-loss arithmetic. A root multiplier is computed independently from original data. Each exact/fixedpoint output must equal the strict exact-LP rejection; each dual output must equal its own reference and must not prune an LP-feasible threshold. Both targets must XOR correctly, input bits must stay unchanged and workspace must return zero.

Budget: one circuit at a time, max150000 wires, max2000000 gates, max60 seconds construction; recorded caps remain outcomes. Derive resource vectors from each actually constructed circuit, separately from gate-output simulation. Start with selected n=12,18,24 timing inputs to estimate run cost, then execute the complete registered set if bounded. A predicate mismatch or dirty workspace is an immediate affected-claim research-integrity stop with its retained encoding. No hardware account/job, manuscript edit, original code/raw-data edit or full-walk claim.

Metrics: CIRCUIT OUTPUTS SIMULATED; exact reference values/resources DERIVED; caps/time MEASURED; sample policy/seed/budgets HARDCODED. No regression or scheduled-query validation.
