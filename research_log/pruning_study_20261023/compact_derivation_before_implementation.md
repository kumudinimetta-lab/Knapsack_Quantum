# Compact in-place arithmetic sensitivity pilot: derivation before code

2026-10-23. Separate from pinned production circuits.py and broad-run artifacts. Fixed depth d is a classical parameter; prefix d bits and tau remain quantum inputs. Scope is tiny nonempty instances plus one fixed-depth pilot slice, not a coherent full walk or an optimal arithmetic network.

Verified primary source before implementing primitives: Steven A. Cuccaro, Thomas G. Draper, Samuel A. Kutin, David Petrie Moulton, "A new quantum ripple-carry addition circuit," arXiv:quant-ph/0410184v1 (22 October 2004), https://arxiv.org/html/quant-ph/0410184v1 . Full primary text read. Use the simple MAJ/UMA construction in Section2/Figures1-4 and the high-bit comparison idea in Section4.3. We do NOT implement the optimized Section3/Figure5 pseudocode, so its 2n-1/5n-3 gate formula is not attributed to our implementation.

MAJ(a,b,c): CX(a,b);CX(a,c);CCX(c,b,a). Algebra: a becomes a XOR ((a XOR b) AND (a XOR c)) = majority(a,b,c); b=a XOR b; c=a XOR c. UMA(a,b,c): CCX(c,b,a);CX(a,c);CX(c,b). Applied after MAJ this restores a,c and puts a XOR b XOR c in b. Ripple MAJ over i=0..n-1 with c=cin for i0 and c=a[i-1] otherwise, then ripple UMA in reverse. cin starts0 and is restored0; a preserved; b becomes a+b mod2^n. Optional carry-copy is unnecessary for modular additions used here. Every operation has an explicit inverse by reversing the X/CX/CCX list.

Comparator: flip each right operand bit, set cin1, ripple MAJ(left,~right,1), copy NOT finalcarry to a target, reverse all MAJs, reset cin and complement flips. Since finalcarry of left+~right+1 equals [left>=right], target XOR NOTcarry equals target XOR[left<right]. All operands are restored. This is an unsigned comparison; operand widths must cover live values. No high-bit discarded addition is subsequently interpreted as a comparison.

Controlled constant addition: load k in a reusable all-zero scratch word using CX(control,scratch[j]) at set bits of k; run modular MAJ/UMA addition scratch->accumulator; unload scratch with the same CX gates. For unconditional k use X loads. Subtraction uses the inverse of the adder list. Constants and controls remain unmodified. Constant multiplication c*y into accumulator uses shifted copies of y for each set bit of c and repeated additions, with the same scratch word/carry reused. No quantum divider or multiplier black box.

Root dual fixed-depth construction: use reduced a/b root multiplier, r_i=b*v_i-a*w_i, N0=aW+sum max(r_i,0). Accumulate assigned selected weight and loss L (selected negative-r_i penalty or excluded positive-r_i penalty), then add b*tau into that loss accumulator. Compare N0<L+b*tau and W<assignedweight. Their OR flips the target using CX,CX,CCX; then reverse the complete forward work list. Capacity and bound flags need OR, since on overweight prefixes both can be true. Widths: weight >=bit_length(W+sumw)+1, loss >=bit_length(max(N0,sum|r_i|+(2^tb-1)b))+1; scratch word has maximum arithmetic width. These bounds are the same unsigned bounds as the out-of-place circuit.

Exact LP fixed-depth construction: accumulate assigned weight, assigned P and residual R=W-assignedweight, separately flag capacity infeasibility. On each suffix item compute enough=[R>=w_i], take=active AND enough, split=active AND NOT enough. Retain O(m-d) clean-history flags for reversible traversal. Update P+=v_i and R-=w_i under take; at split compare P*b_i+R*a_i<tau*b_i using reduced v_i/w_i=a_i/b_i, reusable numerator and threshold product accumulators, and the same ripple primitives. Uncompute each numeric product before reuse; retain its comparison flag until global reversal. Active starts capacity-feasible and becomes active AND enough at each suffix item. Each feasible branch has at most one split; split flags and final all-fit flag are mutually exclusive. Target flips for infeasibility, each split AND comparison, and all-fit AND[P<tau], then all work is reversed. Widths cover feasible P<=sumv and 0<=R<=W, numerator P*maxw+W*maxv and max encoded tau*maxw. On infeasible inputs R wraps modulo2^wb, but active0 prevents those bound comparisons from affecting output; such branches are uncomputed exactly.
